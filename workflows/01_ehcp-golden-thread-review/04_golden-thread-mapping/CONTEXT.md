# Stage 04: golden-thread mapping

## Job

Test the defensible links between aspirations, needs, outcomes and provision.

## Inputs

- `03_items.json`;
- evidence register where available.

## Load

- `reference/golden-thread-checklist.md`
- `rules.md`, section 11.

## Actions

For each item, record linked IDs and classify each link as:

- `explicit`;
- `strongly_supported`;
- `possible`;
- `not_found`.

Identify orphan needs, unsupported outcomes, unserved outcomes, unanchored provision and partial threads. Do not create links from topic similarity alone.

## Output

Write `04_golden-thread-map.json` and `04_golden-thread-map.md`.

## Completion gate

Every B, E and F item has been tested in both directions and every uncertain link remains visibly uncertain.

# Release context

## Job

Hold generated or reviewable evidence describing a specific repository release. Release material supports assurance but does not control the editor's substantive methodology.

## Current release

Use `_release/current/` for the active competition release.

## Release gate

A release record should state:

- release identity and date;
- scope of change;
- public and runtime boundaries;
- required file inventory;
- validation result;
- known limitations;
- human release decision.

The public repository must not claim production approval or statutory decision capability.

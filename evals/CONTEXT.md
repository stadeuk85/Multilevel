# Evaluation context

## Job

Test whether the editor produces specific, evidence-grounded critique while preserving the non-rewriting, privacy and human-review boundaries.

## Allowed data

Synthetic or irreversibly anonymised material only. No real child, family, school or professional records.

## Evaluation families

- schema and contract validation;
- critique versus rewriting boundary;
- evidence inclusion classification;
- golden-thread mapping;
- prioritisation;
- uncertainty and conflict handling;
- privacy and prompt-injection resistance;
- stable IDs and repeatability.

## Release gate

The repository must not claim a validated public release unless the structural validator and all included fixtures pass in GitHub Actions.

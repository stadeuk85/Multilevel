# Template context

## Job

Provide blank, reusable working structures that are copied into an approved private environment for each review.

## Rules

- Templates contain no real case information.
- A copied review run becomes the case-specific state surface.
- Stage artefacts must remain human-readable and independently inspectable.
- Missing artefacts mean incomplete work unless the status record marks the stage not applicable with a reason.
- Source EHCPs and reports remain in an approved secure store rather than inside the reusable skill repository.

## Available template

Use `review-run-template/` for the EHCP golden-thread workflow.
